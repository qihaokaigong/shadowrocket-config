# Third-party rule data

Generated releases include rule data downloaded from
[Loyalsoldier/surge-rules](https://github.com/Loyalsoldier/surge-rules), which is
distributed under GPL-3.0. The source URLs and exact content hashes used by a
release are recorded in `upstream/lock.json` and the published
`metadata.json`.

The upstream project states that its generated data is assembled from multiple
community-maintained sources. Review its README and source repository before
adding a new source or changing redistribution behavior.
